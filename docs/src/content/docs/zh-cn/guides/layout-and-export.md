## 画板

图形放置在按页面组织的无限画板上。拖动图框时会自动吸附到页面网格、
页边距以及相邻图框的边缘；吸附可在工具栏中关闭。工具栏的排列菜单提供
对齐（选中两个及以上图框）、水平 / 垂直分布（三个及以上）、层叠顺序，
以及 *Tidy up frames*（一键整理）命令。

在画板空白处拖动可框选页面和工作表图框。按住 `Shift` 可追加框内图框，按住
`Ctrl`（macOS 上为 `Cmd`）可切换框内图框。拖动任一所选图框的标题栏会移动
整个选择，并可作为一步撤销。在 Canvas 列表中，`Shift` + 单击选择连续区间，
`Ctrl` + 单击添加或移除单个画布。`Ctrl` + `A` 会根据最近使用的区域全选图框
或画布。

## 添加外部图片

若要让每张图片各占一个适配大小的页面，请从 File 菜单、Ribbon 或命令面板选择
**Add Images…**。一次可以选择多张 PNG、JPEG、TIFF、WebP 或 BMP 图片。也可以
直接把文件拖到画板上；即使落点位于已有页面内，每张图片仍会新建一个页面。

若要把图片放进已有 Panel，请先选中或进入未锁定的 Panel，再把文件拖入绿色轮廓。
若要粘贴图片或复制的一组图片文件，请使用 **Paste Image**，或按 `Ctrl`/`Cmd` +
`V`。在 Windows 上，可以从文件资源管理器复制文件，也可以从 Paint 等应用复制
图片像素。光标位于文本框中时，该快捷键仍会正常粘贴文本。

PlotX 创建图片页面时，会优先采用图片的 DPI 信息确定实际尺寸；没有 DPI 信息时按
96 DPI 计算。页面宽度不超过 89 mm，高度保持图片的原始宽高比，图片会无变形地
铺满页面。一次导入多张图片只产生一个撤销步骤；导入失败或取消不会改动项目。

以下格式需要使用专门的命令：

- **Add Animated Image First Frame…** 导入动画 PNG 或 WebP 的第一帧。
- **Add Images Without Metadata…** 先把图片转换为 PNG，以去除元数据，再添加到项目。
- **Add All TIFF Pages…** 添加多页 TIFF 中所有可读取的页面；常规的 **Add Images…**
  只添加第一页。

导入尺寸很大的图片前，PlotX 会要求确认。选中图片后，可在对象检查器的 **Image**
区域裁剪或旋转图片、调整透明度，或选择插值方式。这些调整不会改变嵌入的源图片。

画板使用有内存上限的代理图以保持编辑流畅；SVG、PDF、EMF、PNG、JPEG、TIFF
以及 **Copy Figure** 则从项目中嵌入的原图采样。裁剪、90 度旋转、透明度、适配、
插值、Panel 裁切和图层顺序都会与画板一致，也不依赖源文件原先所在的路径。

若嵌入图片缺失或损坏，项目仍会打开，并在原位置保留带说明的占位项。请在对象
检查器中使用 **Replace Image…** 修复。替换前，常规保存和出版导出会停止；若仍需
生成审阅稿，可在导出对话框中明确允许输出带标签的占位图。

## 使用图版面板

使用 Arrange 菜单或命令面板中的 Panel 命令，可以制作多 Panel 图版。你可以创建
空 Panel、把所选对象组成 Panel，也可以复制、合并、拆分、解散或删除 Panel。
在 Layers 中展开 Panel，即可查看其中的对象。

单击 Panel 内任意位置可将其选中，随后可以拖动整个 Panel，或用四角控制点连同
其中内容一起缩放。按住 `Shift` 单击可选择多个 Panel。若要编辑 Panel 内的对象，
请双击 Panel 或按 `Enter` 进入。点击页面上方的面包屑或按 `Esc` 可返回页面。也可
按住 `Ctrl`/`Cmd` 单击对象，无需先进入 Panel 即可直接选择它。

在 Panel 内，对象会吸附到 Panel 边缘和其他对象。若要把对象移入另一个未锁定的
Panel，请将它拖到目标 Panel 上，待目标高亮后松开。也可以在 Layers 中把对象行
拖到 Panel 行。若目标采用 Stack 或 Grid 布局，内容会在移入后重新排列。隐藏对象
仍可在 Layers 中选择；锁定对象可以选择，但不能编辑。

对象检查器中的 Panel 设置可控制可见性、锁定、裁剪、标签和布局。**Vertical
Stack**、**Horizontal Stack** 与 **Grid** 会按选定的间距、内边距和对齐方式排列
内容。页面有多个可见 Panel 时，自动字母标签才会出现，并按从左到右、从上到下的
阅读顺序排列。标签位于图片上时会自动切换黑白颜色以保持清晰；手工标签和锁定
标签在单 Panel 页面中仍会显示。

## 画布尺寸

活动页面左上角上方会显示一个尺寸标签，内容为当前尺寸和匹配到的预设
（例如 *89 × 60 mm · Nature · Single column*）。点击它、在 Figure Ribbon
选项卡中使用 **Canvas Size & Settings…**，或在命令面板中运行任意
"Canvas Size" 条目，都可以更换尺寸。

预设列表支持搜索并按组显示：期刊图幅宽度（Nature、Science、Cell Press、
ACS、Elsevier、PNAS 和 IEEE，数值取自各出版社的作图规范）、纸张尺寸
（支持纵向/横向切换）、演示文稿幻灯片、最近使用过的条目，以及你自己保存
的自定义尺寸。期刊预设只锁定页面*宽度*——高度由内容决定，上限为该期刊
的最大图幅深度；页面超过该深度时会显示警告。

默认情况下，更改尺寸不会移动或缩放内容；如果对象超出页面，尺寸标签一栏
会出现溢出警告，单击即可把内容等比缩小到页面内（可撤销，字号保持物理磅
值不变）。勾选 **Scale content when applying sizes** 后，应用预设时对象
会随页面一起缩放。

另有两项自动辅助：

- **Auto height**（自动高度）保持宽度不变，页面高度跟随内容深度变化，
  并以期刊最大深度为上限。
- 当布局网格设置为两列及以上、而页面仍是单栏宽度时，会出现一条可关闭的
  提示，单击即可切换到同一期刊的全宽——它绝不会自行改变页面尺寸。

导出对话框会预先选中匹配的期刊预设，因此按栏宽制作的页面默认按该宽度
导出。

## 分图之间的间距

多分图的版面，只有各分图的数据区间隔均匀才好看；但每个图为刻度标签和
轴标题预留的空间各不相同，图框等距往往看起来并不等距。
**Canvas Size & Settings…** 里既设定想要的间距，也设定它按什么来量。

**Minimum spacing**（最小间距）就是这个间距本身，单位与画布一致；
**Tight**（2 mm）、**Normal**（5 mm）、**Spacious**（10 mm）三个预设可
直接填入常用值。

**Spacing basis**（间距依据）决定这个间距量的是哪两处之间：

- **Visual**（默认）量的是相邻两图数据区之间的距离，并把夹在中间的刻度
  标签和轴标题计算在内，因此 y 轴标题较长的分图能自动获得所需空间。该值
  是下限：实际间距只会更宽，不会更窄，图框也不会重叠。
- **Frame** 量的是图框之间的距离，不计轴文字。图框会严格按设定值排开，
  但各对分图数据区之间的可见空隙会随标签长短而变化。

凡是由 PlotX 自动摆放图形的场合都遵循该依据——**Apply grid**，以及把图形
拖到已有图形的页面上时的自动平铺。

把图拖到另一页面，即把它移到该页并重新平铺目标页。拖动过程中图形跟随
指针移动，按下时抓住的那一点始终停在光标下，目标页面上同时画出松手后
各图所在的位置。若目标页面上已有两个及以上的图，整页会重排成均匀网格，
拖入的图落在指针所指的那一格里。

如果这次移动把源页面清空，PlotX 会随本次拖放一并删除该页面，移动与删除
同属一步撤销/重做。释放鼠标时按住 `Alt` 则保留这个空页面；状态栏会提示
当前这次拖放按住 `Alt` 会变成哪种结果。若希望默认保留空的源页面，可在
偏好设置 → General 中打开 **Keep source canvas when tiling its last
object**——此后按住 `Alt` 就只为这一次拖放删除空页面。

使用 Select 工具时，每条非零页边距都会画成一条贯穿页面的虚线，标示出正在
排版的内容区；设为 0 的一边不画线。打开布局网格会另外显示单元格轮廓，
拖动时出现的吸附参考线使用对比色。

## 精简内侧轴

一格格分图共用同一套坐标轴时，每个分图都重复刻度数字和轴标题只会浪费
版面。**Simplify Inner Axes**（精简内侧轴）只在每列最下方的图上保留 x 轴
文字，只在每行最左侧的图上保留 y 轴文字；轴线和短刻度在所有分图上都保留。

两种用法：

- 在画布设置中勾选 **Apply grid** 旁的 **Simplify inner axes**，排布与精简
  合并为一次可撤销的操作。图框会按精简后的坐标轴重新丈量，因此各分图能
  占用原先被隐藏文字占据的空间。
- 对已经排好的图形，可从 Arrange Ribbon 选项卡、画布右键的 Arrange 菜单
  或命令面板运行 **Simplify Inner Axes**。它要求至少有两个图形已对齐成
  网格；否则状态栏会提示需要先做什么。

若要让某个分图重新显示文字，选中它后在对象检查器的 **Axes** 区域操作：
**X text** 与 **Y text** 两行可分别切换 **Tick labels** 和 **Title**，
**Automatic** 则让该轴恢复为两者都显示。

## 堆叠与多数据集图

一个图框可以同时显示多个 1D 数据集——可叠加显示，也可以按可调的垂直
间距与 3D 错切堆叠。2D 数据集则以颜色叠加方式组合。

若要沿 x 轴对齐线条序列，请选中图形，然后在 **Analyze** 页签的 **Align** 组中
选择 **Align Traces…**。当图中至少有两条可见线条序列使用相同的 x 轴单位时，
此命令才可用。也可以从对象检查器的 **Data** 中选择 **Align traces…**，打开
同一个对话框。

选择参考序列后，可用 **Trace start**（第一个有限绘制样本）对齐，也可在指定的
x 区间内按峰对齐。按峰对齐时，**Positive** 查找向上的峰，**Negative** 查找
向下的峰，**Magnitude** 比较两者的突出度。选择 **Apply** 前，请检查
**Anchor**、**Delta** 和 **Result** 列。隐藏、不兼容或没有可用对齐位置的序列会
列为 **Skipped**，并保持不变。

对齐会保留图形当前的缩放范围。若要手动调整一条线，可在 **Data** 中编辑其
**X shift**。自动和手动位移都是可撤销的图形设置，不会改变来源数据或数据导出。

## 作图样式与排印

PlotX 自动按印刷习惯设定图形样式：只保留左轴和底轴、向外的短刻度、随
显示范围调整的刻度精度、图框变窄时抽稀的刻度密度，以及以上标显示的
NMR 核素质量数。新数据集默认使用 89 × 60 mm 单栏画布：单个图占满画布
时，屏幕上看到的字号就是期刊印出的字号；多分图的组合图之后再拼合到更宽
的页面上，各分图保持原始尺寸。

你可以直接控制的部分：

- 选中单个图形后，可在对象检查器的 **Axes** 区域覆盖 X/Y 轴标题或数值
  范围，也可隐藏某条轴的刻度标签和标题。对于真正的 2D NMR 谱，
  **F1/F2 equal scale (1:1)** 让两个坐标轴使用相同的单位/屏幕距离；
  PlotX 在导入谱时设定其初始值，此后可单独修改，且不会改变导入偏好设置。
  标题留空或范围保持 **Auto**，即可继续使用由数据自动推导的值。
  手动范围会成为该轴的完整范围：缩放和平移仍限制在其中，双击图内即回到
  这个手动范围。不显示坐标轴的图表没有轴设置；分类轴不提供范围控制。
- 任意图形都可通过对象检查器的 **Legend & scales** 管理图例与色标。
  **Visibility** 设为 **Auto** 时，图中存在两个及以上命名项便显示分类图例，
  热图则显示连续色标；**Show** 也允许显示单项图例，**Hide** 会隐藏当前图的
  图例或色标。**Position** 可把图例或色标放在图内，或在右侧、下方为其
  预留空间；**Layout** 可把分类图例排成纵向列表或横向一行；**Title** 位于
  该分区的高级设置中。
- 启用 **Select** 后，单击图例或色标可直接打开对应的 **Legend & scales**
  设置。拖动分类图例可自由放置；自定义位置在调整图框尺寸后仍会保留，并用于
  所有导出格式。双击图例或色标可恢复自动位置。
- Figure Ribbon 选项卡的 **Figure Typography…** 一次设定文档内所有图的
  文字尺寸（刻度标签、轴标题、图标题与图例），单位为绝对磅值——这是
  文档级样式，缩放分图不会改变字号。各字号取值 1 到 72 pt；图例默认为
  7 pt。
- 对象检查器的 **Figure typography** 区域中的 **Tick-label size** 就是同
  一个刻度标签字号，并提供 **Legend size** 与 **Legend text color**。
  在两处中任何一处修改，改的都是文档里的同一个值。它属于文档而不属于
  某个图，因此无论当前选中什么（包括什么都没选中）都会显示。
- 对象检查器的 **Line** 区域中的 **Stroke width** 设定所选图中线条序列的
  线宽，单位为 pt；新线条序列默认为 0.5 pt。可以拖动或输入 0.05 到 10 pt
  之间的任意值，也可以从 **Presets**（预设）中取一个——*Fine* 0.50 pt、
  *Medium* 0.75 pt、*Bold* 1.25 pt。只有当所选内容中有以线条绘制的序列时才
  会出现该区域，标题处会数出即将改动的序列条数。选中多个图即一并编辑；什么
  都不选时，作用于页面上的活动图。

  当所选序列的线宽并不一致时，控件显示破折号和 *mixed*，而不会把其中一
  个值当成当前设置；此时写入一个值正是让它们重新一致的方式。所选序列中
  以别的方式绘制的（例如等高线）会在状态栏里报告为跳过，其余序列照常生
  效。若某个线宽不同于 PlotX 会为这份数据选择的值，该行会标上圆点，旁边
  的重置按钮按当前数据重新推导默认值。
- **画布主题**携带配套字号——例如 Presentation Dark 主题会放大坐标轴
  文字以适合投影演示。

图形完成后，见[导出](/zh-cn/guides/exporting/)。
