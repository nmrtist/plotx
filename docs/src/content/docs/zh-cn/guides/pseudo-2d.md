伪 2D 数据集是在某个参数变化下采集的一叠 1D 谱。PlotX 导入时从采集参数
中读取这个变化参数：梯度强度系列标记为 DOSY，延迟系列标记为弛豫
（T1 还是 T2 由你选择的拟合模型决定）。

## 工作流

1. 导入伪 2D 数据集。
2. 在**分析**选项卡的**区域**组中选择**绘制区域**，然后在感兴趣的峰上画出区域。
3. 在区域任务卡片中选择**继续到系列表**。
4. 系列表打开时会同时出现**曲线拟合**任务卡片。确认建议的模型，选择拟合全部
   曲线或一条选定曲线，然后选择**运行拟合**。

## 拟合模型

- 单指数衰减
- 反转恢复（T1），`a + b·exp(−x/T)`
- 饱和恢复
- Stejskal–Tanner 扩散衰减（DOSY）
- 双指数与拉伸指数
- 线性

对 DOSY，**分析**选项卡的 **Experiment**（实验）卡片还提供正则化反拉普拉斯
变换（ILT），可生成完整的化学位移 × 扩散系数图。图在后台构建，期间可继续
操作；按**取消**可丢弃该构建。同一数据集在当前构建完成或取消前不能重复构建
同类图。构建期间修改该数据集的处理参数会取消构建——否则图与谱图将不再对应。
状态栏会在发生取消时提示；处理修改完成后重新构建即可。出于同样的原因，修改
处理参数也会丢弃已经算好的图，画面会退回堆叠图，直到你重新构建。

下一次 ILT 构建所用的设置按以下顺序确定：你在 **Experiment** 卡片中为该数据集
输入的值优先；其次采用该数据集上一次 ILT 结果所用的设置；都没有时，**λ** 取
**Preferences → Processing** 中的默认值，网格参数取 PlotX 内置默认值。
**λ** 的允许范围是 `0.000001` 到 `1000`。

两种 DOSY 图都会随 `.plotx` 项目一起保存，**Show** 和 **DOSY method** 的选择
也一并保存，因此重新打开项目时无需重算即可看到同一张图。如果保存的图所依据的
数据与项目中保存的处理流程重建出的数据不再一致，PlotX 会继续显示保存的图并给出
警告——打开项目时出现在状态栏，同时也出现在 **Experiment** 卡片中。如果保存的图
完全无法读回，PlotX 会改为显示堆叠图，并在同样两处说明。重新构建该图即可消除
警告。

在 **Show** 中选择 **DOSY map**、而当前 **DOSY method** 尚无对应结果时，同样会
显示堆叠图，**Experiment** 卡片会指明需要构建哪张图。

## 关于强度的说明

提取的强度是带符号的（定相后的实部投影），而不是模值，因此反转恢复
数据无需折叠即可正确拟合。
